# Python 实验三：列表、元组、集合深度探究

按《Python 列表、元组、集合 实验实训指导书》完成五个任务：切片删除、嵌套容器可哈希辨析、集合运算与推导式、去重方案对比、两班选课综合统计。**仅使用 Python 标准库**，测试用 `unittest`。

## 功能

1. **任务1 切片删除**：输出三组 `del` 切片的删除前索引、预判值、实际值；复现"边遍历边删除"缺陷并给出两种安全写法。
2. **任务2 可哈希辨析**：逐条探测 `(1,2,3)`、`(1,[2,3])`、`[1,2]`、`frozenset({1,2})`、`{1,2}`，保留原始报错；给出 `frozenset` 嵌套集合的正确写法。
3. **任务3 集合运算**：交集、并集、两个方向的差集、对称差；集合推导式生成 1~30 内 4 的倍数。
4. **任务4 去重对比**：`list(set())` 无序去重、手写保序去重、`dict.fromkeys` 保序去重；嵌套列表转元组去重。
5. **任务5 综合统计**：两班选课编号的保序去重、交集、对称差、差集、交集转元组，每步附文字说明。

## 测试覆盖

共 35 个用例，按任务分组，含以下边界与异常：

- 空列表切片删除、`del ls[::-1]` 删空、切片删除不修改原列表；
- 连续偶数导致循环删除漏删（`[2,4,6] → [4]`）；
- 元组内含列表、普通 set、list 的不可哈希报错；
- 空区间集合推导式返回空集合；
- 空列表去重、嵌套去重不修改原数据；
- 两班均为空时的统计结果。

## 关键结论

1. `del 列表[切片]` 的索引在删除前按原始列表一次性算好，负步长从末尾往前取值。
2. 元组的"不可变"约束引用地址，不约束引用指向对象的内容；含 `list` 的元组整体不可哈希。
3. 普通 `set` 可变不可哈希，需嵌套时用 `frozenset`。
4. `list(set(data))` 丢失顺序且要求元素可哈希；保序去重推荐 `dict.fromkeys`。
5. 边遍历边 `remove` 会漏删，且是否暴露取决于数据分布。
